# UnLondon — Ironsworn Saga

UnLondon hosts **Ironsworn Saga**, a single-page campaign companion for Ironsworn Classic and Delve. The application is deployed through GitHub Pages.

- [Launch Saga](https://woodymellor.github.io/unlondon/)
- [CURRENT_STATE.md](CURRENT_STATE.md) — live development save point, verified baseline, current task, test results and exact next action.
- [ROADMAP.md](ROADMAP.md) — implementation priorities, planned features and deferred work.
- [KNOWLEDGEBASE.md](KNOWLEDGEBASE.md) — index of durable technical evidence and discoveries.
- [DECISIONS.md](DECISIONS.md) — index of established decisions and their provenance.

The ChatGPT Project's `PROJECT_CONTEXT.md` is the single starting point for new conversations. Read it, then the live checkpoint and roadmap. The original documents remain authoritative for their detailed technical and planning content.

## Continuity

Work from the last **user-confirmed stable** build. Read the current checkpoint before changing code; do not assume a test build is stable. Save meaningful progress to `CURRENT_STATE.md` when requested or at significant checkpoints.

## Security

Do not commit credentials or private campaign data. Inspect changes before promoting them to the stable application.
